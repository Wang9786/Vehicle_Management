# FleetFlow｜公務車管理系統

FleetFlow 是一套公務車管理作品集 Demo，將用車申請與行程明細整合為單一管理入口。

> 本公開版本為個人重新設計的展示系統。所有人名、車牌、據點、行程、數據及業務情境均為虛構，不包含任職公司的原始程式碼、內部資料或機密資訊。
  
## 線上展示

[點此開啟公務車管理系統](https://wang9786.github.io/Vehicle_Management/)

## 主要功能

- 總覽、申請紀錄、人員查詢與車輛查詢四個操作畫面
- 依日期、據點、人員與車牌篩選歷史紀錄
- 個人用車次數、跨據點里程與費用摘要
- 車輛近期駕駛、里程、油費與其他費用摘要
- 行程里程、停車費、過路費與其他支出明細
- 查詢結果分頁與側邊明細面板
- 展示資料 CSV 匯出
- 桌面與行動裝置響應式介面

## 系統概念

```mermaid
flowchart LR
    A[虛構用車申請] --> C[資料整合]
    B[虛構行程明細] --> C
    C --> D[查詢與統計]
    D --> E[管理儀表板]
    E --> F[歷史紀錄與 CSV]
```
